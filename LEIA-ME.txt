The Wolf Seller — site estático pronto para a Vercel

1. No GitHub, crie um branch novo (ex.: site-novo).
2. Apague os ficheiros antigos desse branch e carregue TODO o conteúdo desta pasta para a raiz (Add file → Upload files). Commit.
3. Na Vercel → Settings → Build & Deployment:
   Framework Preset: Other · Build Command: (vazio) · Output Directory: . · Install Command: (vazio)
4. Abra o link de Preview do branch e teste.
5. Se estiver tudo bem, faça merge para main. Para voltar atrás: Deployments → versão antiga → Promote to Production.

Páginas: / · /privacidade · /termos · /reembolsos

MODO PRÉ-LANÇAMENTO
O site está em modo pré-lançamento (secção do canal do WhatsApp + botões dos planos a apontar para o canal).
Para voltar ao site normal (botões de registo originais, sem a secção do canal), em index.html troque
  <html data-modo="prelancamento">  por  <html>
O código original dos botões de registo continua no ficheiro (classe only-live).
Backup completo da versão anterior: tag git "pre-lancamento-backup".
